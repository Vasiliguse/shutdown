# Windows Shutdown Timer Pro

Графическая программа для автоматического управления выключением Windows.

## 📋 Возможности

- ⏱️ **Быстрый таймер** - установка времени выключения в часах, минутах и секундах
- 🕐 **По времени** - установка конкретного времени выключения
- 📅 **Расписание** - еженедельное расписание выключений
- 🔔 **Оповещения** - настройка напоминаний перед выключением
- 🎨 **Современный интерфейс** - красивый и удобный дизайн
- 🌍 **Русский язык** - полная локализация

## 🚀 Доступные действия

- **Выключить ПК** - полное выключение компьютера
- **Перезагрузить** - перезагрузка системы
- **Спящий режим** - переход в спящий режим
- **Гибернация** - переход в режим гибернации
- **Только оповещение** - просто уведомление без действий

## 📦 Версии приложения

### 1. PyQt6 версия (shutdown_timer.py)
Современный интерфейс с расширенными возможностями.

**Требования:**
```bash
pip install PyQt6
```

**Запуск:**
```bash
python shutdown_timer.py
```

**Особенности:**
- Красивый современный интерфейс
- 3 вкладки для разных режимов
- Прогресс-бар обратного отсчета
- Еженедельное расписание

### 2. Tkinter версия (shutdown_timer_tkinter.py)
Облегченная версия без внешних зависимостей.

**Требования:**
- Python 3.x (Tkinter включен в стандартную библиотеку)

**Запуск:**
```bash
python shutdown_timer_tkinter.py
```

**Особенности:**
- Не требует установки дополнительных библиотек
- Легкий и быстрый
- Все основные функции

## 🎯 Примеры использования

### Быстрый таймер на 5 минут
1. Откройте вкладку "Быстрый таймер"
2. Установите минуты: 5
3. Выберите действие: "Выключить ПК"
4. Нажмите "Запустить"

### Расписание выключения на конкретное время
1. Откройте вкладку "По времени"
2. Установите время: 22:00
3. Выберите действие: "Спящий режим"
4. Нажмите "Запустить"

## ⚙️ Системные требования

- Windows 7/8/10/11
- Python 3.6+
- 10 МБ свободного места на диске

## 🔒 Безопасность

- Приложение работает с правами пользователя
- Можно отменить выключение в любой момент кнопкой "Отменить"
- Пользователь получает подтверждение перед запуском таймера
